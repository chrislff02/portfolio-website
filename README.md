# Christian Franco Portfolio

A personal portfolio website built with React, TypeScript, and Vite.

The site showcases my projects, technical skills, background, and contact information with a retro terminal inspired design.

## Features

- Responsive layout for desktop & mobile
- Retro terminal inspired interface
- Custom pixel/dot portrait rendered with HTML Canvas
- Project cards with live demo and GitHub links
- Skills and technologies section
- Smooth navigation between sections
- Navbar that hides while scrolling down and reappears when scrolling up
- Contact links for Email, GitHub, and LinkedIn

## Built With

- React
- TypeScript
- Vite
- CSS
- HTML Canvas

## Sections

- Hero
- About
- Projects
- Skills
- Contact

## Running Locally

- Clone the repository
- Navigate into the project: cd portfolio-website
- Install dependencies: npm install
- Start the development server: npm run dev

Then open the local URL provided by Vite in your browser.

## Build

- To create a production build: npm run build
